* `config.py`: contains configuration information such as number of latent dimensions, default model type, and paths to all saved file locations.
* `make_applications.py`: runs all applications.
* `make_data.py`: runs all data.
* `make_comparison.py`: runs all comparisons.
* `make_figs.py`: runs all figures.


* `generate_simulations_chaotic.py`: used to generate the simulations for the chaotic consortia.
