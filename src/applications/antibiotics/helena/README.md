# Applications
Use this directory to run the antibiotic tasks related to Helena's work. This code will need to be updated prior to running, because it used some obsolete functions and classes.

## Dirs
* `cache`: used to store files

## Files
* `main.py`: primary file for tasks.
* `inputs.py`: used to load and label data from Helena's dataset
* `figure_panels.py`: used to create plots from Helena's work
