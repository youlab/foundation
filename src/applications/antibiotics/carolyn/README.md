# Applications
Use this directory to run the antibiotic tasks related to Carolyn's work.

## Dirs
* `cache`: used to store files

## Files
* `main.py`: primary file for tasks.
* `data.py`: used to load and label data from Carolyn's dataset
* `config.py`: used to label data from Carolyn's work
* `write_antibiotic_summary.py`: used to summarize results from classification task
