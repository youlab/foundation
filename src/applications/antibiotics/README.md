# Applications
Use this directory to run the antibiotic tasks.

## Directories
* `carolyn`: contains files relevant to Carolyn's work on antibiotic resistance
* `helena`: contains files relevant to Helena's work on antibiotic resistance. These are not included in the publication, but are in the code for potential future use.
* `kyeri`: contains files relevant to Kyeri's work on antibiotic resistance

## Files
* `main.py`: primary file for running tasks related to figure 3.
* `generate_results.py`: task agnostic code used to generate predictions using different inputs, relies on `loop_for_results.py`
* `loop_for_results.py`: task agnostic code used to generate predictions at different training sizes
