# Applications
Use this directory to run the exp consortia tasks.

## Directories
* `cache`: used to store files

## Files
* `abundance_detailed.py`: uses the foundation model to analyze consortia growth curves with limited datasets, not currently used in the paper
* `final_abundance_classification.py`: used to predict the final abundance of each member in a consortium
* `main_epsilon.py`: used to process the forecasting results and report metrics
* `main_predictions.py`: used to make predictions and forecasts
* `regressor_accuracy.py`: used to analyze the accuracy of the regression models, not currently used in the paper
* `resolution.py`: uses the foundation model to analyze consortia growth curves with limited datasets, not currently used in the paper
* `config.py`: used to define which consortia to analyze
