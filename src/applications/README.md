# Applications
Use this directory to run the applications for the paper. Each sub-directory should have a main function that can be pulled into `main.py` to run. The `main.py` is run using the `app.py` file in the `src` directory.

## Directories
* `antibiotics`: antibiotic tasks
* `consortia`: simulated consortia tasks
* `consortia_exp`: experimental consortia tasks
* `datasets`: classes related to data
* `karlsson`: tasks involving forecasting using the external-to-corpus Karlsson dataset
* `super_resolution`: super resolution tasks
* `utils`: utility functions for the tasks

## Files
* `config.py`: contains some values for use throughout the tasks
