# Figs
Use this directory to create the figures for the data. Relevant files will be imported into the `main.py` file in the `figs` directory.

## Files
* `main_beta.py`: primary file for creating figure 1.

    * `three_types.py`: used to create figure 1
* `interpolation.py`: used to create figure for presentation
* `truncate_and_normalize.py`: used to create figure for presentation
* `animation.py`: used to create figure for presentation
