# Figs
Use this directory to create the figures for the experimental consortia tasks. Relevant files will be imported into the `main.py` file in the `figs` directory.

## Files
* `main_epsilon.py`: primary file for creating figure 5.
    * `experiment_conditions.py`: used to create figure 5
    * `plot_abundance_classification.py`: used to create figure 5
    * `plot_forecast_rmse.py`: used to create figure 5
* `for_presentation.py`: used to create figures for presentation
* `supplemental_curves.py`: used to create supplemental figure
