# Figs
Use this directory to create the figures for the model. Relevant files will be imported into the `main.py` file in the `figs` directory.

## Files
* `main_beta.py`: primary file for creating figure 2.
    * `examples_beta.py`: used to create figure 2
    * `model_comparison.py`: used to create figure 2
    * `model_reconstruction_accuracy.py`: used to create figure 2
    * `reconstruction_pipeline.py`: used to create figure 2
    * `twod_by_source.py`: used to create figure 2
    * `examples.py`: used to create figure 2
* `training_dataset_comparison.py`: used to create supplemental figure
* `supplemental.py`: used to create supplemental figure
* `plot_intrinsic_dimensions.py`: used to create supplemental figure
* `dataset_level_splits.py`: used to create rebuttal Figure R1 / Supplementary Figure S3 (dataset-level retraining)
* `sim_fraction_sensitivity.py`: used to create rebuttal Figure R6 / Supplementary Figure S2 (simulation-fraction sensitivity, train and test rows)
* `supp_table_14.py`: used to create Supplementary Table S14 (dataset-level split summary and per-file split assignments)
* `twod_visualization.py`: used to create figure for presentation
* `architecture.py`: referenced in another file, may be obsolete
