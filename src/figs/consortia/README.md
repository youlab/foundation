# Figs
Use this directory to create the figures for the simulated consortia tasks. Relevant files will be imported into the `main.py` file in the `figs` directory.

## Files
* `main_epsilon.py`: primary file for creating figure 4.
    * `data.py`: used to create figure 4
    * `sliding_window.py`: used to create figure 4
    * `pipeline.py`: used to create figure 4
* `supplemental_curves.py`: used to create supplemental figure
* `supplemental_consortia_overview.py`: used to create supplemental figure
    * `sample_focal_community.py`: used to create supplemental figure
    * `simulated_consortia_counts.py`: used to create supplemental figure
    * `estimated_intrinsic_dimensions.py`: used to create supplemental figure
* `input_to_prediction.py`: used to create figures for presentation
* `simple_complex.py`: used to create figure for presentation
