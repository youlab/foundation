# Figs
Use this directory to create the figures for the antibiotic tasks. Relevant files will be imported into the `main.py` file in the `figs` directory.

## Files
* `main_gamma.py`: primary file for creating figure 3.
    * `antibiotic_classification_pipeline.py`: used to create figure 3
    * `antibiotic_regression_pipeline.py`: used to create figure 3
    * `classify_antibiotic_resistance_f1_score.py`: used to create figure 3
    * `classify_antibiotic_treatment.py`: used to create figure 3
    * `increasing_sparsity.py`: used to create figure 3
    * `regress_antibiotic_concentration.py`: used to create figure 3
    * `resistance_classification_pipeline.py`: used to create figure 3
* `kyeri_concentrations.py`: used to create figure for presentation
* `kyeri_keio.py`: used to create supplemental figure regarding Kyeri's data
* `kyeri_timer.py`: used to create supplemental figure regarding Kyeri's data
* `kyeri_top10f.py`: used to create supplemental figure regarding Kyeri's data
* `plot_antibiotics_summary.py`: used to create supplemental figure summarizing performance of different models on the antibiotic tasks
* `carolyn_examples.py`: used to create figure for presentation
* `kyeri_treatments.py`: used to create figure for presentation
* `data_sparsity.py`: used to create figure for presentation
