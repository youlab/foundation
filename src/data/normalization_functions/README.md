# Data
This directory contains scripts relevant preprocessing the data

## Files
* `general.py`: provides default preprocessing code
* These are all preprocessing scripts specific to a certain dataset
    * `helena.py`: preprocessing for Helena's data
    * `rohan.py`: preprocessing for Rohan's data
    * `microbiome_gaussian.py`: preprocessing for the microbiome datasets
* `utils.py`: utility functions for preprocessing the data
