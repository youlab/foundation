# Machine Learning
This directory contains scripts relevant to building and training the machine learning models used in this project.

## Dirs
* `datasets`: this directory has code for the datasets used in the training of the machine learning models
* `fine_tune`: this directory is used to fine tune models on a smaller dataset, not used in the paper
* `models`: this directory has the machine learning models
* `regression`: this directory has custom regression models, not used in the paper
* `trainers`: this directory has trainers for the machine learning models

## Files
* `neural_system.py`: related to the neural ODE model, not used in the paper
