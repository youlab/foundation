# Machine learning
This directory has code for the trainers used to train the machine learning models in this project

## Files
* `mcr_trainer.py`: trainer for the MicroBERT Curve Reducer transformer model
* `pr_trainer.py`: trainer for the PCA reducer
* `trainer.py`: trainer for the variational autoencoder models

* the following files are related to models not used in the paper
    * `neural_trainer.py`: defines the trainer for the neural ODE
